# Decision records

Each record here is one decision: what was asked, what was chosen, and why, with what was found on the way.
[`ARCHITECTURE.md`](../ARCHITECTURE.md) says how the app works now, and leaves a heading and a sentence where a record's whole text would otherwise be, so a citation such as `§3, "The drawing file"` still leads here.

A record describes the feature as it stands, so when a decision changes, amend its record in the same pull request.
A new decision gets the next number and a line below, and is written one sentence per line.
